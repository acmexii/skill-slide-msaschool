# MSASchool Purple 디자인 규격

## 시각 기준과 자산

원본 `assets/msaschool-original.pdf`는 44장, 960×540pt의 16:9 자료다. `assets/reference.pptx`는 1600×900 CSS px의 16:9 적용 예다. 크기가 다르면 모든 위치와 크기를 같은 비율로 환산한다. 원본의 세밀한 서식과 실제 적용 예를 함께 보되, 작은 글자를 그대로 복제해 발표 가독성을 떨어뜨리지 않는다.

`assets/cover-background.png`는 원본 PDF 1쪽에서 제목과 교육 로고만 제외해 렌더링한 배경이다. 오른쪽의 대각선 협업 사진, 왼쪽의 희미한 사진, 보라색 세로 띠와 옅은 가로선이 포함된다. 배경 사진은 새 내용의 수행 실적을 증명하는 자료가 아니다.

## 색과 글꼴

| 용도 | 기준 |
|---|---|
| 배경 | 흰색 `#FFFFFF` |
| 주요 강조·표 머리행 | `#67519E` |
| 강한 강조·단계 선택 | 원본의 `#54239D` 또는 `#553CC4` |
| 본문·제목 | `#262626` |
| 보조 문구 | `#686868` |
| 설명 영역 | `#F5F7F8` 또는 `#F6F8F9` |
| 표의 분류 열 | 옅은 보라색 `#F1EDF7` |
| 얇은 경계선 | `#D4D4D4` |
| 보조 카테고리 | 원본의 청록색 계열 `#5C95A6`, 필요한 경우만 |

제목은 Gmarket Sans Medium, 본문은 Freesentation Regular를 기준으로 한다. PDF 인코딩 이름은 `GmarketSansMedium`, `Freesentation-4Regular`이며 설치 환경에서는 `Gmarket Sans`, `Gmarket Sans Medium`, `Freesentation`, `Freesentation 4 Regular` 같은 이름으로 표시될 수 있다. 실제 설치명·렌더링을 확인해 지정한다. 원래 서체를 찾을 수 없으면 조용히 다른 글꼴로 바꾼 뒤 동일하다고 주장하지 않는다. 가까운 한글 산세리프 대체를 사용했다면 전달 시 간단히 밝힌다.

1600×900 적용 예의 크기: 표지 제목 52px, 본문 장표 제목 38px, 설명 28px, 본문 26~28px, 표 머리행 24px, 주석 20~22px, 페이지 번호 18px. 제목은 과도하게 굵게 하지 않는다. 긴 문장은 먼저 줄바꿈과 공간을 조정하고 중요한 내용을 생략하지 않는다.

## 공통 본문 배치

1600×900 적용 예의 위치를 안내값으로 사용한다.

- 제목 왼쪽 세로선: x51, y48, w6, h47. 제목: x74, y44, w1260, h76.
- 설명: x74, y131, w1430, h65. 오른쪽 상단 브랜드: x1380, y52, w157, h34. 로고는 원래 비율 유지.
- 본문은 대략 x80~1520, y210~800을 사용한다. 하단 출처·단위·주의 문구 영역과 충돌하지 않게 한다.
- 기존 장표에 불필요한 키커·탭·푸터를 더하지 않는다. 섹션 표기는 좌하단 18px, 페이지 번호는 우하단 18px 수준으로 작게 유지할 수 있다.

## 표와 설명 영역

표는 native table로 유지한다. 보라색 머리행에 흰색 글자, 옅은 분류 열, 흰색·연회색 행, 얇은 회색 구분선을 사용한다. 행 높이는 내용에 따라 배분하고 셀 여백을 확보한다. 원본의 교육과정 세로 분류 열은 실제 계층 구조가 있을 때 활용한다. 모든 표에 장식용 병합 셀을 추가하지 않는다.

설명 영역은 밝은 회색 바탕과 가는 회색 테두리, 작게 둥근 모서리로 구성한다. 보라색 소제목과 검은 본문을 사용한다. 강조 띠와 청록색 캡션은 원본 화면 묶음 방식에 맞을 때만 사용한다.

## 매뉴얼·설명서·소개서의 상세 화면 설명

서비스 소개서·매뉴얼·사용 설명서는 독자가 화면을 보며 기능과 사용법을 이해할 수 있도록 상세히 작성한다. 제안서에는 기존의 간결한 설명 규격을 유지한다.

- 실제 서비스 화면에서 설명할 조작부·정보 영역 옆에 ①, ②, ③ 등의 번호를 배치하고 설명란의 항목에도 동일한 번호를 붙여 일대일로 대응시킨다. 번호는 슬라이드 안에서 중복·누락되지 않게 하고 여러 장에 걸친 절차는 흐름을 알아볼 수 있게 한다.
- 번호 표시는 편집 가능한 배지·도형과 텍스트로 올린다. 사용자 제공 [참조 이미지](../assets/manual-numbered-screen-reference.png)처럼 빨간 원·흰 숫자·검은 외곽선으로 화면과 설명란에서 동일하게 표시한다. 설명 소제목과 슬라이드 강조선은 보라색을 유지한다. 화면의 버튼명·값·메뉴를 가리지 않으며, 대상이 모호하면 얇은 연결선이나 확대 화면을 사용한다. 원본 스크린샷의 정보는 변조하지 않는다.
- 각 설명은 번호와 화면 항목명, 기능의 목적, 조작 방법, 확인 가능한 결과·상태를 근거에 맞게 기술한다. 필요한 경우 선행 조건이나 주의사항을 덧붙인다. 소개서는 기능과 활용 의미를, 매뉴얼·설명서는 조작 순서와 결과를 중심으로 충실히 설명하며 화면만 보고 확인할 수 없는 동작을 만들어내지 않는다.
- **설명란 본문은 14pt**로 지정한다. 위의 일반 장표 설명 28px 기준보다 이 문서 유형의 14pt 기준을 우선한다. PowerPoint의 실제 pt 설정을 확인하고, CSS px를 쓰는 제작 도구는 문서의 실제 슬라이드 폭과 캔버스 폭의 비율로 환산한다. 예를 들어 실제 폭 960pt를 1600px 캔버스에 매핑하면 14pt는 약 23.33px이며, 14px로 잘못 지정하지 않는다.
- 참조 이미지처럼 상단 제목·보라색 요약 아래에 좌측 약 70~75%의 큰 서비스 화면과 우측 약 25~30%의 상세 설명란을 기본으로 배치한다. 우측 설명란은 옅은 테두리로 구분하고, 번호+보라색 항목명 아래에 14pt 설명 본문을 둔다. 화면과 설명이 일대일로 대응하도록 항목 사이의 여백을 확보한다. 내용과 화면 비율에 따라 상하 배치로 조정할 수 있다. 화면과 해당 번호별 설명은 반드시 동일 슬라이드·동일 PDF 페이지에 함께 배치하고, 설명을 별도 페이지나 부록으로 분리하지 않는다. 내용이 넘치면 14pt를 유지하면서 설명란 폭·높이, 화면 크롭·크기, 문단 간격과 여백을 조정하고 중복 표현을 정리하되 기능·사용 방법·결과의 핵심 설명은 보존한다. 고정된 좌우 비율보다 동일 페이지 배치와 가독성을 우선한다. 그래도 들어가지 않으면 임의로 페이지를 나누지 말고 필요한 범위 조정을 사용자에게 확인한다.
- 최종 PPTX와 PDF에서 화면과 모든 대응 설명의 동일 페이지 배치, 화면 번호와 설명 번호의 일치, 설명 누락, 14pt 설정, 연결선과 화면 글자의 겹침, 설명 잘림을 확인한다.

## 화면·도해·표지

화면은 본문 면적을 충분히 차지하도록 크게 배치한다. 원본 비율을 유지하고 필요한 영역만 프레이밍한다. 크롭 후 클래스명, 표 제목, 관계선, 판단 결과가 잘리지 않았는지 확인한다. 렌더링에서 수동 크롭이 무시될 수 있으므로 설정값만으로 완료를 판단하지 않는다.

표지 제목은 사진의 대각선을 넘지 않는 왼쪽 밝은 영역에 놓는다. 원본의 교육 제목·고객명·날짜·로고를 새 발표에 그대로 남기지 않는다. 사진을 교체하는 경우에도 밝은 왼쪽 제목 영역과 오른쪽 대각선 사진의 관계를 유지한다.
